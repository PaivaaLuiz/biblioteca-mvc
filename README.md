#  Read Book

Sistema de gerenciamento de livros desenvolvido em Flask utilizando arquitetura MVC.

##  Funcionalidades

-  Catálogo de livros
-  Pesquisa por título e autor
-  Cadastro de livros
-  Edição de livros
-  Exclusão de livros
-  Login para administrador
-  Layout responsivo
-  Banco de dados PostgreSQL

##  Tecnologias

- Python
- Flask
- SQLAlchemy
- PostgreSQL
- Bootstrap 5
- HTML5
- CSS3
